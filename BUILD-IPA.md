# Как получить `.ipa` без Mac — пошагово

MacBook не нужен. `.ipa` соберёт бесплатный сервер GitHub (macOS-раннер),
а подпишет и установит его Sideloadly прямо на Windows.

Итого: ~15 минут, 0 ₽, компилировать самому ничего не надо.

**Что понадобится:** Windows-ПК с браузером, iPhone + кабель, обычный
(бесплатный) Apple ID, аккаунт GitHub (создаётся за минуту).

---

## Часть 1. Собрать `.ipa` (~5 минут)

### Шаг 1. Аккаунт GitHub

Если нет — <https://github.com/signup>. Бесплатного хватает.

### Шаг 2. Новый репозиторий

1. Справа сверху **«+» → New repository**.
2. **Repository name:** `caterpillar`
3. **Public** (на публичных репозиториях macOS-раннеры GitHub бесплатны
   без лимита; приватный тоже подойдёт, но там тратятся минуты аккаунта).
4. **Create repository**.

### Шаг 3. Загрузить файлы проекта

1. Распакуйте `CaterpillarRepo.zip` — получится папка `repo` с правильной
   структурой внутри.
2. На странице пустого репозитория нажмите ссылку
   **«uploading an existing file»**.
3. Откройте папку `repo` и перетащите в браузер **всё её содержимое**
   (`Ctrl+A`): `Caterpillar`, `docs`, `preview`, `scripts`, `tools`,
   `README.md`, `BUILD-IPA.md`, `.gitignore` и `.github`.

   > Именно содержимое, а не саму папку: иначе файлы окажутся на уровень
   > глубже.
   >
   > `.github` и `.gitignore` начинаются с точки — браузер такие файлы иногда
   > молча пропускает. Шаг 4 проверяет именно это.

4. Внизу **Commit changes**.

### Шаг 4. Проверить, что сборка на месте

В списке файлов репозитория должен быть путь
`.github/workflows/build-ipa.yml`.

Если папки `.github` нет (браузер иногда пропускает папки с точкой):

1. **Add file → Create new file**;
2. в поле имени вставьте целиком: `.github/workflows/build-ipa.yml`
   (слэши сами создадут папки);
3. вставьте туда содержимое файла `docs/github-workflow.yml` из архива;
4. **Commit changes**.

### Шаг 5. Запустить сборку

1. Вкладка **Actions**.
2. Если сверху просят — нажмите **«I understand my workflows, go ahead and
   enable them»**.
3. Слева **Build unsigned IPA** → справа **Run workflow** → **Run workflow**.
4. (Если вы загружали файлы через браузер, сборка могла уже запуститься
   сама — тогда просто откройте её.)

### Шаг 6. Забрать `.ipa`

1. Дождитесь зелёной галочки (~3–5 минут).
2. Откройте этот запуск, прокрутите вниз до блока **Artifacts**.
3. Скачайте **Caterpillar-unsigned-ipa** (это zip).
4. Распакуйте — внутри `Caterpillar.ipa`.

Всё, `.ipa` на руках. Артефакт хранится 30 дней, пересобирать можно
бесконечно.

---

## Часть 2. Подписать и установить (~10 минут)

### Шаг 7. Sideloadly

1. Скачайте <https://sideloadly.io> и установите.
2. Из Microsoft Store поставьте **iTunes** (или iCloud) — Sideloadly нужны
   драйверы Apple, без них телефон не увидится.

### Шаг 8. Подключить iPhone

Кабель → на телефоне «Доверять этому компьютеру» → разблокировать.

### Шаг 9. Подписать

1. В Sideloadly перетащите `Caterpillar.ipa` в окно (или выберите через
   иконку IPA).
2. **Apple ID** — свой обычный. Пароль лучше вводить в появившемся окне
   запроса, а не хранить в программе.
3. **Start**. Первый раз займёт 1–3 минуты (создаётся сертификат).

### Шаг 10. Доверить профиль

На iPhone: **Настройки → Основные → VPN и управление устройством →
Разработчик … → Доверять**.

### Шаг 11. Добавить виджет

1. Запустите «Гусеницу» один раз (это обязательно, иначе виджета не будет
   в галерее).
2. Зажмите пустое место на рабочем столе → **«+»** → найдите **Гусеница** →
   выберите **средний** виджет (это и есть 2×4).

## Что важно знать про бесплатный Apple ID

| | |
|---|---|
| **Срок** | 7 дней, потом приложение и виджет перестают открываться |
| **Как продлить** | Sideloadly → тот же `.ipa` → Start (переподпись, ~1 минута) |
| **Лимит** | 3 приложения одновременно; приложение + расширение-виджет = 2 App ID из 10 в неделю |
| **Платный аккаунт** ($99/год) | год без переподписи, лимитов нет |
| **TrollStore** | если ваша версия iOS поддерживается — навсегда и без подписи |

Виджет ставится вместе с приложением: расширение подписывается тем же
сертификатом. Если в галерее виджетов пусто — переустановите через Sideloadly
и перезагрузите iPhone.

## Как обновить приложение (когда я прислал новые файлы)

Проект уже в репозитории, поэтому обновляются только изменённые файлы —
и сборка запускается сама после каждого коммита.

1. Откройте папку в репозитории, например
   `Caterpillar/Shared` (просто кликните по папкам в списке файлов).
2. **Add file → Upload files**.
3. Перетащите туда новые файлы (`CaterpillarArt.swift`, `CaterpillarPose.swift`).
4. Внизу **Commit changes**.
5. Повторите для `Caterpillar/Widget`, если там тоже есть новые файлы.
6. Подождите 3–5 минут → **Actions** → последний запуск → **Artifacts** →
   скачать свежий `.ipa` → Sideloadly → Start (переустановка поверх старой
   версии).

После переустановки виджет лучше удалить с рабочего стола и добавить заново,
чтобы он не показывал старый кадр.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| На вкладке Actions пусто / «Workflows aren’t being run» | Settings → Actions → General → **Allow all actions** |
| Сборка красная | Откройте запуск → красный шаг → пришлите мне текст ошибки, поправлю |
| «Artifacts» нет | Артефакт появляется только после успешной сборки |
| Sideloadly не видит iPhone | Поставьте iTunes/iCloud из Microsoft Store, другой кабель/порт, разблокируйте телефон |
| `Unable to install` | Переподключите кабель, перезапустите Sideloadly, проверьте, что Apple ID верный |
| Виджета нет в галерее | Запустите приложение, переустановите, перезагрузите iPhone |

## Альтернативы GitHub

* **GitHub Desktop** (Windows, GUI) — распаковать папку, «Publish repository»,
  и `.github` точно загрузится. Дальше те же шаги 5–6.
* **Аренда облачного Mac** — MacinCloud / Scaleway за 1–2 $ в час: открыть
  Xcode, `bash scripts/build-ipa.sh`, забрать `.ipa` через файлообмен.
* **Codemagic** — тоже собирает из репозитория, но настройка длиннее.
* **Знакомый с Mac** — один раз `bash scripts/build-ipa.sh`, дальше `.ipa`
  подписываете у себя на Windows.
